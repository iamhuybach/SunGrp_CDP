# Instructions for every agent in this repository

This repository holds only the BRD, Mapping, and document model for CDP, a customer data platform. It contains no source code.

1. Before doing anything, identify your role. The user must name it or attach one of these files:
   - `docs/agents/opus-analyst.md` — business analysis, document model, template and architecture changes.
   - `docs/agents/composer-writer.md` — repository operations, writing the BRD and Mapping.
   - `docs/agents/codex-reviewer.md` — review, read-only.
2. If your role is unclear, ask the user and write no file.
3. Read your role file and `docs/model/DOCUMENT_MODEL.md` before working. Do only the work your role file allows. Write only the paths your role file allows.
4. The workflow order is in `README.md`.
5. Reply to the user in Vietnamese. Keep paths, IDs, and status values in English.
6. Never commit or push unless the user explicitly asks.
