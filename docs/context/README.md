# Sự kiện dùng chung

Thư mục này chứa sự kiện dùng chung cho nhiều yêu cầu, ví dụ danh mục hệ thống nguồn, từ điển dữ liệu đã duyệt, chính sách dữ liệu cá nhân của dự án. Giá trị trích từ đây có `evidence_status` là `REPO_STATED` (`docs/model/DOCUMENT_MODEL.md` mục 6.1).

- Chỉ người dùng ghi vào thư mục này. Opus, Composer và Codex chỉ đọc.
- Mỗi file chia mục có tiêu đề để `context_ref` trỏ được dạng `<path> §<mục>`.
- Không ghi giá trị dữ liệu cá nhân, secret hay dữ liệu trích từ môi trường thật (model mục 14).

Hiện chưa có file nào.
