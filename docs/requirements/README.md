# Tài liệu theo yêu cầu

Mỗi yêu cầu có một thư mục `<doc_key>/`, `doc_key` dạng `YYYYMMDD-slug`. Bố cục và người ghi từng file ở `docs/model/DOCUMENT_MODEL.md` mục 3 và 13.

```text
<doc_key>/
  inputs/        người dùng
  evidence/      người dùng
  ANALYSIS.md    Opus
  BRD.md         Composer
  MAPPING.md     Composer
  reviews/       chép nguyên văn từ Codex
```

Hiện chưa có yêu cầu nào.
